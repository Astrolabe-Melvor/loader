Astrolabe Loader - mod loader for Melvor Idle 2
==============================================

INSTALL
1. Open the game folder (Steam > right-click Melvor Idle 2 > Manage > Browse local files).
2. Extract this zip there, so "override.cfg" sits next to "Melvor2.exe".
3. Start the game. A green "Astrolabe Loader" tag shows in the top-left corner; F1 opens the Mods menu.

MODS
Each mod zip extracts into the game folder the same way and lands in "mods\<ModName>\".

UNINSTALL
Delete "override.cfg" and the folder "data_MelvorModLoader_windows_x86_64". The game then runs untouched.
Your "mods" folder can stay.

AFTER A GAME UPDATE
If the game does not start, delete "override.cfg" and wait for an updated loader.
